## Platform
web

## Stack
Astro static HTML with TypeScript for the questionnaire and SVG/Canvas export. This follows the lightweight implementation proposed in the conversation; implementation details delegated by the build request. Cloudflare Workers static assets deployment.

## Users
English-speaking visitors looking for a 7 deadly sins test they can immediately take on a phone or desktop. English locale inferred from the requested SEO keyword and confirmed as the working assumption while optional clarification remains open.

## Product Purpose
Take a personality-themed entertainment questionnaire on the first screen, receive seven independently scored results, read explanations, and save a shareable result image.

## Capabilities and Constraints
Use public-domain IPIP question wording directly, with traceable sources. Seven-sin categorization is a site-authored interpretation, not an IPIP-validated scale or diagnosis. No invented population norms. No account or payment requirement. Answer storage and image generation in the browser. Primary homepage keyword: 7 deadly sins test. Publish to Cloudflare. Source repository: toolution/seven-deadly-sins-test, current available user organization (default tool inaccessible). User-selected production domain: https://7deadlysinstestfree.com/. The www hostname redirects permanently to the apex domain.

## Brand Commitments
Website visual design uses impeccable. Latest user instruction explicitly pins the same UI as the supplied reference screenshot: white background, large dark-gray headings, black outlined seven-sided sectors, same surrounding colorful icons, strongest-sin sentence underneath, green share button, blue linked tiles. User-provided reference icons extracted from the supplied screenshot at the user’s request. Prior lavender visual direction is superseded.

## Evidence on Hand
IPIP permission: https://ipip.ori.org/newPermission.htm. Alphabetical item list: https://ipip.ori.org/AlphabeticalItemList.htm. IPIP NEO-related items: https://ipip.ori.org/newNEOKey.htm. No clinical validation or visitor benchmarks for this site's interpretation.

## Product Principles
- Answer the first question without a start screen.
- Every item has a source and explicit scoring direction.
- Explain the interpretation and limitations plainly.
- The downloaded result agrees with the displayed scores.
